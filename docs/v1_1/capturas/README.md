# Capturas sugeridas para v1.1

Realizar entre cinco y siete capturas, sin credenciales ni secretos:

1. Formulario de libro con el campo Año y un valor válido.
2. Catálogo con filtro Año combinado con al menos otro filtro y el valor conservado.
3. Sesión de asistente mostrando alta o edición bibliográfica de un libro.
4. Restricción del asistente ante una URL reservada, mostrando HTTP 403 sin datos privados.
5. Módulo admin de usuarios asistentes con username, nombre y estado, sin contraseñas.
6. Cambio de estado de un asistente y posterior reactivación, sin mostrar credenciales.
7. Render con el servicio v1.1 en estado Live y una vista pública final por HTTPS.

No capturar contraseñas, hashes, `DATABASE_URL`, `SECRET_KEY`, tokens ni información privada innecesaria.
