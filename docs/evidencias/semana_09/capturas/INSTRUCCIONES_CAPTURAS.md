# Instrucciones para capturas finales de la Semana 9

## Alcance

Realice únicamente cinco capturas finales. No repita toda la evidencia de semanas anteriores. Guárdelas en esta carpeta con los nombres indicados.

Antes de capturar:

- cierre gestores de contraseñas y otras pestañas;
- oculte notificaciones del sistema;
- no muestre contraseñas, tokens, `DATABASE_URL`, `SECRET_KEY`, Deploy Hook ni datos personales reales;
- use únicamente información institucional autorizada o una vista sin datos sensibles;
- revise cada PNG antes de añadirlo a Git.

## 1. Sistema Live y catálogo público

Archivo: `01_catalogo_publico_live_semana09.png`

1. Abra <https://biblioteca-quinones.onrender.com/>.
2. Espere a que cargue por completo.
3. Deje visible la barra con `https://` y el catálogo con sus filtros.
4. No abra el formulario de login.

Debe probar: URL pública, HTTPS y catálogo operativo.

## 2. Panel administrador

Archivo: `02_panel_admin_semana09.png`

1. Inicie sesión fuera de la captura.
2. Abra **Administración**.
3. Muestre las tarjetas principales y el rol verificado.
4. No muestre el formulario de login ni credenciales.

Debe probar: acceso admin y módulos principales.

## 3. Terminal QR

Archivo: `03_terminal_qr_semana09.png`

1. Abra **Escaneo** con sesión autorizada.
2. Muestre el terminal, botones de cámara e ingreso manual.
3. Mantenga la cámara apagada si podría capturar personas o espacios privados.
4. No registre un préstamo solo para obtener la captura.

Debe probar: terminal accesible y alternativa manual.

## 4. Reporte

Archivo: `04_reporte_semana09.png`

1. Con rol admin, abra **Reportes**.
2. Seleccione RPT-01 Inventario o un reporte sin datos personales.
3. Muestre las pestañas RPT-01 a RPT-04 y la tabla.
4. Si usa otro reporte, oculte nombres reales de lectores antes de capturar.

Debe probar: módulo de reportes operativo.

## 5. Render Live

Archivo: `05_render_live_semana09.png`

1. Abra el servicio `biblioteca-quinones` en Render.
2. Muestre nombre del servicio, rama `main`, estado `Live` y último deployment.
3. Oculte o recorte variables de entorno, Deploy Hook, tokens, correo, IDs privados y logs con datos sensibles.

Debe probar: servicio Live y commit desplegado.

## Revisión final

- [ ] Son exactamente las capturas útiles solicitadas.
- [ ] Los nombres coinciden.
- [ ] Se leen el estado o módulo relevantes.
- [ ] No hay secretos ni credenciales.
- [ ] No hay datos personales de lectores.
- [ ] No se afirma una entrega o firma que aún no ocurrió.

Después de incorporarlas, actualice `SEMANA_09_EVIDENCIA.md` y `CHECKLIST_ENTREGA.md` con el resultado real.
