# Evidencias del Proyecto

Cada semana debe almacenar sus evidencias en `semana_XX/`.

Contenido recomendado por semana:
- `SEMANA_XX_EVIDENCIA.md` — resumen verificable de lo realizado.
- Capturas de funcionalidades implementadas.
- Resultados de pruebas.
- Scripts o documentos relevantes.
- Hash/enlace del commit correspondiente.
- Enlace de deployment si aplica.
- Observaciones y acciones manuales realizadas.

Las evidencias deben reflejar resultados reales; no deben fabricarse capturas, resultados o validaciones.
