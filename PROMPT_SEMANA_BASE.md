# Prompt Base — Inicio de Cada Semana

Sustituye `[NÚMERO]` por `01`, `02`, etc., y el nombre de la semana cuando corresponda.

---

Trabaja exclusivamente en la **Semana [NÚMERO]** definida en el Documento Maestro v1.0 de este proyecto.

Antes de modificar cualquier archivo:

1. Lee `AGENTS.md`.
2. Revisa el Documento Maestro v1.0.
3. Lee `docs/ESTADO_PROYECTO.md`.
4. Lee `docs/REGISTRO_CAMBIOS.md`.
5. Inspecciona el estado actual del código y del repositorio Git.
6. Revisa las evidencias y commits de las semanas anteriores cuando sean relevantes.
7. Verifica qué actividades de esta semana ya están completadas y cuáles faltan.

Después desarrolla todas las actividades correspondientes a la Semana [NÚMERO], respetando estrictamente el Documento Maestro y sus criterios de aceptación.

No avances a actividades pertenecientes a semanas posteriores salvo que sean estrictamente necesarias como requisito técnico para completar o probar correctamente la semana actual.

Durante el trabajo:
- mantén el código sencillo, organizado, mantenible y entendible;
- no cambies reglas de negocio, arquitectura, tecnologías, roles, alcance o modelo de datos sin señalarlo primero y obtener aprobación;
- ejecuta las pruebas necesarias;
- verifica los criterios de aceptación aplicables;
- no expongas ni subas credenciales, contraseñas, tokens o archivos `.env`;
- guarda las evidencias relevantes en `docs/evidencias/semana_[NÚMERO]/`;
- crea o actualiza `SEMANA_[NÚMERO]_EVIDENCIA.md` dentro de esa carpeta;
- actualiza `docs/ESTADO_PROYECTO.md` al terminar;
- registra en `docs/REGISTRO_CAMBIOS.md` únicamente cambios estructurales previamente aprobados.

Al finalizar, dame un resumen breve y comprensible indicando:
1. Qué se realizó.
2. Qué archivos principales se crearon o modificaron.
3. Qué pruebas se ejecutaron y cuál fue su resultado.
4. Qué criterios de aceptación se comprobaron.
5. Dónde quedaron guardadas las evidencias.
6. Qué commit o commits corresponden al trabajo realizado.
7. Si existe alguna acción manual que yo deba realizar.
8. Cualquier problema, pendiente o decisión que haya surgido.

No continúes con la siguiente semana hasta que yo revise y apruebe el resultado.
